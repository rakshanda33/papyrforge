# PDFForge

PDFForge is a learning-first project 
I’m building to understand how PDF processing works under the hood and how to build a safe, reliable backend around it. 
I want to explore what makes PDFs large, compare compression methods, learn how pages are rendered and converted, and understand how files should move through a backend processing system. 

**The goal is to learn the engineering behind these operations, not just wrap PDF tools in a user interface.**
